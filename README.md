# 名刺ベース（meishi-base）

名刺を登録・整理・共有できるアプリ。`index.html` 1ファイルで動きます。

## 2つのモード（設定画面で切替）
- **ローカル保存**：この端末の中だけに保存。ログイン不要・すぐ使える（共有はできない）。
- **クラウド共有**：Supabase につないでログインすると、同じアカウント同士で名刺を共有できる。

## 主な機能
- 名刺の登録・編集・削除（氏名／会社／部署／役職／電話／携帯／メール／住所／Web／タグ／メモ）
- 📷 写真よみとり（Gemini APIキーを設定に貼ると、名刺を撮影→自動入力）
- 🔍 検索・タグ絞り込み、👥 自分の名刺／共有の切替表示
- 🗓️ 出会った記録（日付・場所）、✅ フォローアップToDo
- 📱 電話・メール・地図をタップで起動
- 📤 自分の名刺を QR / vCard で渡す、CSV・vCard で書き出し

## クラウド共有の準備（使うときだけ）
1. Supabase でプロジェクトを作る（既存プロジェクトに相乗りしてもOK）。
2. `setup.sql` を Supabase の SQL Editor に貼って実行。
3. アプリの設定 →「クラウド共有」→ URL と anon key を保存 → メール/パスワードでログイン。

## 写真よみとりの準備（使うときだけ）
Google AI Studio で Gemini APIキーを取得し、設定画面に貼るだけ。

## メモ
- QRは `easyqrcodejs`（日本語対応のため）。無印の qrcodejs は日本語で壊れるので使わない。
